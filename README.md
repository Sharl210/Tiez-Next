## 这是什么

Tiez-Next 是一个以 Rust 为核心的剪贴板管理器：复制过的文字、富文本、图片、文件路径都会自动留存，随时检索、随时粘贴；可以用标签归类、给条目写备注，也可以通过 WebDAV 或 MQTT 在多台设备之间流转。

界面基于 Tauri 2，后端为 Rust，数据全部保存在本机。

## 核心功能

### 记录与检索
- **自动采集**：文字、富文本 (HTML)、图片、文件与目录路径都会记录；连续快速复制的多张图片不会丢失。
- **全局搜索**：按内容、来源应用、标签或日期检索。搜索时不会弹出标签面板遮挡结果。
- **顺序粘贴**：为高频办公场景设计的顺序拷贝 / 顺序粘贴工作流。
- **粘贴即置顶**：从标签管理里粘贴同样计入记录，并出现在主页面最新位置。

### 标签与条目
- **多色标签**：自定义颜色分类整理。
- **标签分组可自由增删**：包括内置分组在内都能删除，**删除分组不会连带删除条目**。
- **移动与复制到标签**：把一个条目移到另一个标签，或让它同时属于多个标签。
- **分组操作走右键菜单**：重命名与删除在标签上右键触发，不占用标签本身的显示空间。
- **任意条目可编辑**：文字类可直接改正文（富文本保存前会提示格式将转为纯文本）；图片、文件类可编辑备注。
- **条目备注**：给任意条目添加备注，标签管理与主页面均可查看。
- **表情管理**：内置 Emoji 表情库，支持快捷搜索与输入。
- **隐私脱敏**：识别身份证、手机号、邮箱等信息，预览时自动脱敏。

### 窗口与外观
- **多屏友好**：在主副屏之间切换时窗口保持在原来的屏幕上，不会跟着鼠标跳；在另一块屏上点击也不会把窗口关掉或自动置顶。
- **贴边收纳**：支持自动停靠屏幕边缘，节省桌面空间且随时呼出。
- **主题**：支持 云母 / 亚克力 背景效果与暗黑模式，内置多款调优主题。
- **分栏比例记忆**：调整过标签管理的分栏比例后会被记住，下次打开直接就是那个比例。

### 数据安全
- **备份与恢复**：一键导出全部数据为 zip（数据库、附件、表情收藏、自定义背景），导入即完整恢复；导入前会自动备份当前数据，导入失败不破坏现有数据。
- **迁移中心**：集中管理旧数据目录，支持手动迁移与清理。迁移**只读取**来源目录、**不改动原数据**，可以反复执行；删除前会明确提示风险并自动备份。
- **拒绝外来包**：不导入其他应用（含旧版 TieZ）导出的备份，避免误操作。
- **前后向兼容**：备份包在后续版本之间保持可读，未知字段会被忽略而不是报错。

### 网络与同步
- **WebDAV 同步**：数据由你掌控，跨设备同步历史记录。
- **MQTT 协议**：轻量协议同步方案，适应不同网络环境。
- **局域网传输**：在局域网内传输文件与内容。
- **秒传验证码**：手机端收到的短信验证码，快速同步至当前设备。

### AI 接入（MCP）
内置 MCP（Model Context Protocol）服务，让 AI 客户端可以读取、搜索、编辑剪贴板历史与标签。

- **默认已开启**，默认允许写入，默认无需鉴权，默认端口 **23123**，默认**只监听本机**
- 端点：`http://127.0.0.1:23123/mcp`
- **支持局域网访问**：在设置里打开后服务改绑 `0.0.0.0`，同一网段的其他机器可以连接
- **可开启令牌校验**：打开后客户端需在请求头带上 `x-mcp-token`
- 读取内容**不做截断**，AI 拿到的是完整正文
- 通过 MCP 修改条目与在界面上操作**走同一套逻辑**，敏感标签的加密处理不会因入口不同而遗漏

> **关于默认值**：出厂的「免鉴权 + 仅本机」组合是安全的，因为只有本机进程能连上。**一旦开放局域网，请先打开令牌校验**——这两个开关相互独立，局域网本身不提供任何身份验证。

## 从源码构建

需要 Node.js 与 Rust 工具链。

```bash
npm install
npm run tauri:build:win     # 交叉编译出 Windows 安装包
```

在 Linux / WSL2 上交叉编译 Windows 产物需要 `cargo-xwin`；产物位于 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`。

## 从旧版迁移

如果你之前用的是旧版（TieZ），**升级后不会自动搬运数据**——这是刻意的，避免在你不了解的情况下改动原目录。

请到「设置 → 数据与迁移」手动选择旧数据目录执行迁移。迁移只读取来源、不改动原数据，可以反复执行与反复验证。若旧版是便携版，数据在程序目录下的 `data/` 里。

## 相对原版（TieZ）的差异

本项目由 TieZ 演进而来。下面列出所有**行为差异**——包括新增能力、修复的问题，以及**移除的功能**。从原版升级前请先看这一节。

### 新增能力

| 能力 | 说明 |
| :--- | :--- |
| **标签条目移动 / 复制** | 把一个条目移到另一个标签，或让它同时属于多个标签。 |
| **条目备注** | 任意条目（含图片、文件）都能加备注，标签管理与主页面均可查看。 |
| **任意条目可编辑** | 文字类可直接改正文；图片、文件类可编辑备注。 |
| **AI 接入（MCP）** | 内置 MCP 服务，AI 客户端可读取、搜索、编辑剪贴板历史与标签。 |
| **备份与恢复** | 一键导出全部数据为 zip，导入即完整恢复；导入前自动备份。 |
| **迁移中心** | 集中管理旧数据目录，手动迁移与清理；支持从旧版及历史 Tiez-Next 迁移。 |
| **多屏友好** | 主副屏之间切换时窗口留在原屏，不跟随鼠标跳转，也不被自动置顶。 |

### 修复的问题

| 问题 | 原版表现 | 现在 |
| :--- | :--- | :--- |
| **删除标签分组会连带删数据** | 删除分组时把组内条目一起删掉 | 只解除关联，**条目保留** |
| **连续复制图片被吞** | 快速连续复制多张图片时部分丢失 | 不再丢失 |
| **复制链接粘贴只剩标题** | 粘贴出来只剩网页标题，看不到链接 | 保留链接本身 |
| **搜索时标签面板遮挡** | 一搜索就展开标签面板挡住结果 | 不再弹出 |
| **内置分组无法删除** | 内置分组删了会自动重建 | 所有分组都可删，**删除后不会重建** |
| **标签管理粘贴不计入记录** | 从标签管理粘贴不产生记录 | 同样计入，并出现在主页面最新位置 |
| **分栏比例每次重置** | 调整后重开就恢复默认 | 记住比例，且**打开瞬间即为记忆值**（无跳变） |

### 移除的功能

| 功能 | 原因 |
| :--- | :--- |
| **在线主题商店** | 它依赖原项目的服务器，本项目没有该服务；**继续兼容其主题包格式也非本项目方向**。因此整个商店（浏览、上传、评分、账号）连同入口一并移除。 |
| **官方网站入口** | 原官网属于原项目，本项目没有官网。 |
| **问题反馈入口** | 原入口指向原项目的邮箱，本项目没有对应渠道。 |

> **主题切换功能本身保留**：内置主题仍可正常切换使用。仅移除**在线商店**部分。
> 如果你此前选用过商店里的主题，升级后会自动回退到内置默认主题，界面不会异常。

### 不兼容原版备份包

备份包带有应用标识校验：**本项目不会导入原版 TieZ 导出的备份**（格式不同，强行导入可能损坏数据）。请使用原版自带的方式保留原数据，再用本项目的「迁移中心」搬运。

## 版本记录

### v0.5.0

**新增**

- **标签分组排序**：可按名称（`A-Z` / `Z-A`）、最近使用、条目数、内容体积排序，每个维度都有正反两个方向；默认按名称，选择会被记住。
- **图标全部更换**：托盘、任务栏、安装器与 README 的图标原先都是原版的（托盘是个字母「Z」）。现在换成不带文字的剪贴板图形标，16×16 下仍可辨认。
- **MCP 默认开箱可用**：默认开启、默认允许写入、默认免鉴权、默认端口 `23123`，默认仅监听本机。

**修复**

- **迁移可能把无关文件搬进数据目录**：选中一个「装着旧数据的目录」而非数据目录本身时，整个目录树会被复制进应用数据目录，数据落在应用不读的位置，界面却提示「迁移完成」。最坏情况会把私钥、合同这类文件一并搬进去。现在会在复制前拦下并给出准确的下一步提示（「请往下再选一层」）。
- **「移动到标签 / 复制到标签」看不到已有标签**：从主列表打开时目标候选是空的，只能手打标签名。
- **标签分组右键菜单的 5 条测试是空断言**：它们在「菜单根本打不开」的实现上也会通过，等于没测。已补存在性前置。
- **MCP 开关改动不即时生效**：关闭写权限、打开令牌校验原先要等重启才起作用。
- **主题商店残留**：已选过商店主题的用户升级后可能拿到一个没有任何样式对应的主题 id。

**安全加固**

- **备份路径护栏下沉**：原先只有界面侧校验备份输出路径，MCP 可绕过。指向数据目录内的 `clipboard.db` 会**截断正在使用的数据库**。护栏已移到所有导出路径的唯一汇聚点。
- **收窄应用可打开的外部链接**：`opener:default` 权限自带 `http://*` / `https://*` 通配范围，与白名单是「或」关系，等于白名单失效。已改为只保留显式白名单。
- **云同步不再携带 MCP 设置**：包括访问令牌与「是否允许局域网访问」等开关，避免被篡改的远端快照在本机种下危险配置。
- **移除上游公告上报**：原会每天向原项目服务器发送带机器标识的请求。

**移除**

- **在线主题商店**（含入口与文案）。理由见上文「移除的功能」。

## 维护约定

**每个版本的功能变化，都必须同步写进本 README。** 具体地：

1. 新增功能 → 写进「核心功能」对应小节，并在「相对原版（TieZ）的差异 → 新增能力」中补一行。
2. 修复问题 → 在「差异 → 修复的问题」中补一行（若该问题原版也存在）。
3. 移除功能 → 必须在「差异 → 移除的功能」中记录，并说明原因。**移除项不能只字不提**——升级的用户需要知道什么东西不见了。
4. 行为变更（含默认值、交互方式变化）→ 同样记入差异表。
5. 每次发版前检查本节是否与代码一致；**README 与实际行为不符视为缺陷**。

这条约定的目的：让"这个版本和原版到底有什么不同"始终有一个**单一、可信、随版本更新**的答案，而不是散落在提交记录里。
