## Tiez-Next v0.5.2

本版修复 **v0.5.1 装机后才暴露的三个问题**。

> 如果你是为了迁移问题来的，请直接使用 **v0.5.3 或更新版本** —— 迁移已重做，不再需要退出应用。

### 修复

**迁移报「另一个程序正在使用此文件」**

在「迁移中心」里指定旧数据目录后迁移失败，提示该文件正被另一个程序使用。

- 现在会明确告诉你占用者是 **Tiez-Next 自己**（不是别的软件 —— 否则你会去关无关的程序）。
- **连带修掉一个更隐蔽的问题**：改名进行到一半失败时，已经改名的文件原先会留在原处没人放回 —— 你会看到「迁移失败」但目标目录里数据不见了。现在失败时会**逐个还原**，并如实告知「目标目录已恢复成你操作前的样子」。

**「备份列表」的刷新按钮一直在闪**

那其实是一个**无限刷新循环** —— 列表每渲染一次就重新拉取一次数据，几百毫秒内会发出上百次请求。现在每次打开只拉取一次。

图标本身也没转（缺旋转动画），只是在两个图标之间高频切换，看起来就是「闪」。

**「备份列表」的界面割裂感**

- 来源标签（「立即备份」/「启动备份」）原先长得太像按钮，连看图都容易误认成按钮 —— 现在明确是标签（左侧竖条 + 语义图标 + 不同字重）。
- 工具栏三个按钮风格不统一（一个无边框、一个带边框）—— 现在逐字段一致。
- 底部提示文字对比度过低：**浅色主题下最低只有 2.20**（可读标准是 4.5）。现在六套主题全部升到 **6.5 以上**。
- 标题与路径行没有层级、关闭按钮过大 —— 一并调整。

按「**保持现有配色与结构、只把层级和一致性做对**」的方式修，没有重新设计。

### 安装

下载下方的 `Tiez-Next_0.5.2_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）

### 说明

- **迁移问题未在真实 Windows 环境端到端复现**（本机开发环境的行为与 Windows 不同，该场景只在 Windows 发生）。如遇问题请反馈。
