## Tiez-Next v0.5.6

本版修好了两个**此前根本不能用**的功能，并补齐了标签输入的手感。

### 备份与恢复

- **恢复现在真的能用了**。此前「导入备份」和「恢复」在 Windows 上**必然失败**并提示"文件被占用" —— 原因是应用要在自己运行期间替换正在使用的数据库，而 Windows 不允许这样做。这不是偶发错误，是每次都会失败。
- 现在恢复改为**两步**：点下恢复只是"准备好"，**重启应用后**才真正替换数据。
- **重启提示也从"建议"变成了"必须"** —— 此前那句"请重启"其实什么都不会发生，重启后数据不会变。现在它就是恢复生效的方式。
- **如果忘了重启、又点了一次恢复**：以后一次为准（不会两次混在一起），并会告诉你上一次的暂存已清理。
- **「立即重启」按钮修好了**。它此前会先启动新进程、再关闭旧进程，而新进程会被"已有实例"的检查挡掉 —— 结果是窗口关了、什么都没起来。现在会等旧进程退出之后再启动。

### 富文本

- **编辑富文本不再变成纯文本**。此前编辑这类条目并保存后，格式会被清除、条目变成纯文本，而且**无法撤销**。
- 现在编辑时保留原有排版，保存后仍是富文本，复制出去也带格式。
- 已经**被降级过的历史条目无法恢复**（它们的格式当初就被删掉了），只能保证今后不再降级。

### 标签输入

- 输入后按**前缀**匹配：打 `i` 优先给出 `ims`、`img` 这样的标签；想找中间含关键词的（例如输入"配置"找"底层ims配置下发"）也仍然能搜到。
- 第一项**默认选中**，按 **Tab 直接采用**（有候选时 Tab 采用、无候选时正常移出输入框）。
- 最多显示 4 行，超出可以用鼠标滚轮查看。
- 「编辑备注」的图标改成了与备注前面那个 **✨ 相同**的图标，并带主题色 —— 一眼能看出它是"备注"。

### 其他

- 修了一批**点了没反应的按钮**：快速粘贴修饰键、macOS 的 Dock 显示开关，以及几个调用了不存在命令的设置项（云端同步停止、下载链接、窗口焦点恢复、临时图片保存、显示 IP 设置）。其中快速粘贴修饰键与 Dock 开关此前在界面上有选项、功能本身也已实现，只是调用不通。

### 安装

下载下方的 `Tiez-Next_0.5.6_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）

### 说明

- 本次产物在 Linux 上交叉编译完成，**未在真实 Windows 环境安装运行验证**，如遇问题请反馈。
- 备份恢复的两阶段流程依赖"重启后才替换数据"，**建议按以下顺序试一次**：先导出一次备份 → 随便改动几条剪贴板记录 → 导入那个备份 → 点「立即重启」→ 确认数据回到了导出时的样子。
- 富文本编辑在真实 Windows 上的输入法行为（中文输入过程中是否会丢字）**未在真机验证**，如遇问题请反馈。
