## Tiez-Next v0.5.12

### MCP 端口不再自动降级

- **此前**：端口被占用时自动改用后面的空闲端口，MCP 客户端配置的地址会在后台悄悄变化。
- **现在**：严格使用配置端口（默认 23123），被占用时报错而不换端口。

### 端口占用处理工具（仅 Windows）

- 在 MCP 设置的端口旁有一个「端口占用处理」按钮。
- 点击后打开悬浮子页面，自动填入当前 MCP 端口号（也可自行输入其它端口）。
- 检测出占用进程后逐项展示，点击「停止」可结束对应进程。
- 权限不足时会请求管理员权限（UAC 提权）。

### 搜索框标签联想已移除

- 搜索框只保留输入与类型筛选，不再在空输入时弹出标签列表。

### 安装

下载下方的 `Tiez-Next_0.5.12_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）

### 说明

- 本次产物在 Linux 上交叉编译完成，**未在真实 Windows 环境安装运行验证**，如遇问题请反馈。
- 端口占用处理工具仅在 Windows 上可用（其它平台按钮不显示）。
- 本版不涉及数据迁移，可直接覆盖安装。
