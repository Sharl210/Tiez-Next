## Tiez-Next v0.5.14

### 修复端口处理器反复拉起 CMD 与崩溃

- Windows 的 `netstat.exe` / `tasklist.exe` 查询改为隐藏窗口执行，不再反复弹出可见 CMD。
- 同一时间只允许一个端口检测或停止操作，重复点击不会并发启动多个外部命令。
- 同一进程的多条监听记录只读取一次进程身份，减少外部命令调用。

### 权限不足时主动处理

- 停止进程权限不足时，先显示管理员权限确认框。
- 用户确认后才发起 UAC 管理员请求。
- 请求完成后自动重新检测端口，明确显示端口已释放或仍然被占用。
- 用户取消确认或取消 UAC 时不会假装操作成功。

### 搜索栏状态记忆

- 右上角放大镜按钮的开关状态会保存到应用设置。
- 启动首帧先读取本地同步快照，随后用数据库设置校正，避免先展开再闪退。
- 搜索栏开启时按钮使用统一边框并显示明显的亮起反馈。

### 安装

下载下方的 `Tiez-Next_0.5.14_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）

### 验证边界

- 本次产物在 Linux/WSL2 上交叉编译完成，已验证 Windows PE/NSIS 安装包和 `.sig` 文件真实存在。
- 未在真实 Windows 环境安装运行验证；端口检测、UAC 提权和搜索首帧需在 Windows 真机复核。
