## Tiez-Next v0.5.23

### 搜索体验

- 修复主界面正则搜索模式没有真正触发后端正则查询的问题。
- 主界面与标签管理搜索结果中的匹配子串使用橙色背景高亮。
- 高亮通过安全 React 节点渲染，不把搜索内容当 HTML 执行。
- 标签管理搜索弹窗提升背景对比度、磨砂层次和整体可读性。
- 标签组存在备注时显示橙色星星，编辑/添加备注按钮仍保持无色动作图标。

### MCP 输出分页

- MCP 工具调用统一限制序列化结果的字符预算，默认每页约 100,000 字符。
- 超过预算时返回 `page`、`pageSizeChars`、`hasMore`、`nextPage`、`totalChars` 和 `dataChunk`。
- `tools/list` 为工具输入参数补充可选分页字段，短响应保持原结构。
- 不静默截断超长响应，AI 可按 `nextPage` 继续读取。
