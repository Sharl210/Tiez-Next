## Tiez-Next v0.5.13

### 端口处理器反馈与标识完善

- 端口处理按钮、检测、停止、管理员权限和结果状态均提供完整中文文案。
- 停止进程前显示处理中；停止后会再次检测端口，只有确认进程已消失才显示“端口已释放”。
- 如果管理员请求被取消、进程仍占用或停止失败，会明确显示失败原因。
- 进程列表显示进程名、PID、可执行文件路径、监听地址和状态。
- 当前 Tiez-Next 进程显示“本 APP 自身”标记，并禁止停止自身。
- 无法读取进程路径时，通过 Windows `tasklist` 继续尝试显示进程名。

### 搜索按钮外观

- 右上角搜索按钮取消突兀的 active 高亮边框，恢复与同排按钮一致的边框、背景和阴影。
- 保留 `aria-label` 与 `aria-pressed`，不影响键盘和辅助技术使用。

### 安装

下载下方的 `Tiez-Next_0.5.13_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）

### 说明

- 本次产物在 Linux/WSL2 上交叉编译完成，已验证 Windows PE/NSIS 产物和更新签名存在，**未在真实 Windows 环境安装运行验证**。
- 端口处理工具仅在 Windows 上显示。
