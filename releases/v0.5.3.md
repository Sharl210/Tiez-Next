## Tiez-Next v0.5.3

本次更新集中在两件事：**迁移功能重做**，以及**设置项的显示与实际状态保持一致**。

### 迁移（请重新试一次）

如果你之前试过迁移但失败了，请用这个版本重试 —— 上一版的问题已经修好。

- **不再需要先退出应用**：现在直接点迁移就行。迁移会先把数据复制到安全位置，然后提示你重启；**重启后自动完成接管**，不需要再做别的。
- **迁移过程有进度显示**：能看到当前在做什么、已处理多少项、已复制多少数据。
- **修好一个可能导致数据看起来丢失的问题**：如果迁移时选的是便携版的**外层目录**，旧版本可能让你遇到"记录都在、图片全打不开"。现在不会了。
- **更安全**：迁移失败时会自动还原已改动的内容，并明确告诉你原目录完好。

### 设置项

这一版着重保证**你在界面上看到的状态就是真实状态**。

- **开机自启动**：以前可能出现"开关显示已开启、实际没生效"。现在设置后会立即核对系统里的真实值，并把结果告诉你；没成功会明确报错。
- **游戏模式**：以前应用会在你不知情的情况下把它改回默认。现在会保留你的选择，并告诉你需要管理员权限才能生效 —— 同时提供一个"以管理员身份重启"的按钮。
- **Win+V 接管**：这个功能在之前的版本里丢失了，现已恢复。如果你之前设置过，会被自动带过来。

### 界面

- 设置页打开时，所有分组都恢复为收起状态（此前 MCP 与自动容灾备份会保持展开）。
- 弹窗不再半透明，读起来更清楚。
- 剪贴板历史的"持久化"默认改为开启（此前默认不保存到磁盘，退出应用即丢失）。

### 安装

下载下方的 `Tiez-Next_0.5.3_x64-setup.exe` 运行即可，支持 Windows 10/11 (x64)。

（`Tiez-Next_0.5.3_x64-setup.exe.sig` 是自动更新用的签名文件，手动安装不需要它。）

### 说明

- 本次产物在 Linux 上交叉编译完成，**未在真实 Windows 环境安装运行验证**，如遇问题请反馈。
- 关于迁移：若你之前迁移失败过，源目录**没有被改动过**，可以放心重试。
