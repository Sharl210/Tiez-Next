## Tiez-Next v0.5.31

- 修复主界面正则 `.*` 卡死和无结果问题，空匹配表达式采用有限安全策略。
- 标签管理搜索的普通/正则按钮与输入框同行，搜索框不再超出容器宽度。
- Ctrl+F 在主界面和标签管理中支持再次按下取消搜索。
- Win+V 唤起应用后，只要鼠标位于 Tiez-Next 窗口内即可使用搜索快捷键，不要求再次点击窗口；鼠标在其他应用区域时不响应。
- 取消置顶后保留条目在列表顶部，置顶背景加深并使用主题兼容颜色变量。

验证：前端 TypeScript 通过；后端 Windows 目标检查通过。WSL2 无法进行真实 Windows GUI 视觉复核。
