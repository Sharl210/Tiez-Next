## Tiez-Next v0.5.0

Tiez-Next v0.5.0

## 新增

- **标签分组排序**：可按名称（`A-Z` / `Z-A`）、最近使用、条目数、内容体积排序，每个维度都有正反两个方向；默认按名称，选择会被记住。
- **图标全部更换**：托盘、任务栏、安装器与 README 的图标原先都是原版的（托盘是个字母「Z」）。现在换成不带文字的剪贴板图形标，16×16 下仍可辨认。
- **MCP 默认开箱可用**：默认开启、默认允许写入、默认免鉴权、默认端口 `23123`，默认仅监听本机。

## 修复

- **迁移可能把无关文件搬进数据目录**：选中一个「装着旧数据的目录」而非数据目录本身时，整个目录树会被复制进应用数据目录，数据落在应用不读的位置，界面却提示「迁移完成」。最坏情况会把私钥、合同这类文件一并搬进去。现在会在复制前拦下，并提示「请往下再选一层」。
- **「移动到标签 / 复制到标签」看不到已有标签**：从主列表打开时目标候选是空的，只能手打标签名。
- **MCP 开关改动不即时生效**：关闭写权限、打开令牌校验原先要等重启才起作用。
- **主题商店残留**：已选过商店主题的用户升级后可能拿到一个没有任何样式对应的主题 id。

## 安全加固

- **备份路径护栏下沉**：原先只有界面侧校验备份输出路径，MCP 可绕过。指向数据目录内的 `clipboard.db` 会**截断正在使用的数据库**。
- **收窄应用可打开的外部链接**：`opener:default` 权限自带 `http://*` / `https://*` 通配范围，与白名单是「或」关系，等于白名单失效。已改为只保留显式白名单。
- **云同步不再携带 MCP 设置**：包括访问令牌与「是否允许局域网访问」等开关。
- **移除上游公告上报**：原会每天向原项目服务器发送带机器标识的请求。

## 移除

- **在线主题商店**（含入口与文案）。主题切换功能本身保留，内置主题不受影响。

## 说明

- 完整差异（含相对原版 TieZ 的全部改动）见 README 的「相对原版（TieZ）的差异」与「版本记录」两节。

（`.sig` 后缀的是自动更新用的签名文件，手动安装不需要它。）
