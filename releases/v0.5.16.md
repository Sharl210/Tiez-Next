## Tiez-Next v0.5.16

### 端口查询与输入修复

- 只把 `LISTENING` 状态当作端口占用监听进程，不再展示 `TIME_WAIT` 等无效连接。
- 进程已经退出或当前权限无法访问时，会明确标记“进程已退出或无法访问”，停止按钮禁用，避免对陈旧 PID 误操作。
- MCP 设置中的端口输入现在可以正常点击、聚焦、选择和修改。
- 端口占用处理弹窗中的端口输入也可以正常编辑和检测其它端口。
- 设置页输入控件显式退出窗口拖拽区，避免 WebView2 把输入点击当成拖动窗口。

### 验证边界

- 前端 325 tests、后端 550 tests 通过。
- Windows 目标交叉编译通过。
- 真实 Windows 端口列表和输入焦点仍需真机安装复测。
