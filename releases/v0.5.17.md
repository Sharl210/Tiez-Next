## Tiez-Next v0.5.17

### 标签管理入口

- 标签管理条目的打开/备份入口改用 ✨ 图标，和富文本操作语义保持一致。

### MCP 富文本编辑

- `update_entry_content` 支持 `htmlContent` 可选参数。
- 对 `rich_text` 条目传入 HTML 时保留富文本格式，不会因编辑正文自动降级。
- 新增独立 `convert_entry_to_plain_text` 工具，只有明确调用转换时才移除 HTML 格式。

### 编辑弹窗

- 富文本编辑弹窗加入 ✨「转换为纯文本」按钮。
- 按钮使用独立的强调样式，与取消/保存操作区保持层级区分。

### 验证边界

- 前端 325 tests、后端 550 tests 通过。
- Windows 目标交叉编译验证通过。
